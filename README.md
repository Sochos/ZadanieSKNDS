Raport z analizy danych o diamentach oraz budowy modelu predykcyjnego mającego na celu oszacowanie ich cen.

Raport zawiera:

1. Przygotowanie danych
2. Oczyszczenie danych
3. Analizę statystyczną w środowisku RStudio
4. Wnioski
   
Tutaj link do mojego raportu na stronie Rpubs: https://rpubs.com/Wikts/ZadanieSKNDS

Oceniono dopasowanie modelu, jego dokładność oraz zgodność z założeniami regresji liniowej

Wyniki zbudowanego modelu potwierdziły wysoką skuteczność oraz możliwość praktycznego wykorzystania modelu do prognozowania wartości diamentów.
